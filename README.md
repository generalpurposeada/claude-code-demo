# claude-code-demo
Demo repo for Claude Code screenshots

## How to open it

`index.html` is a tiny to-do list with no build step and no dependencies.

- **Quickest:** double-click `index.html` (or drag it into a browser window).
- **From a terminal:** run `open index.html` on macOS, `xdg-open index.html` on Linux, or `start index.html` on Windows.

Add an item with the box at the top, tick the checkbox to mark it done, and click × to remove it. Your list is saved in the browser's local storage, so it's still there when you reopen the page.
