# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

Demo repository used to produce Claude Code screenshots and class demonstrations. There is no application code, build system, linter, or test suite.

## Permission rules

`.claude/settings.json` denies `Read(./private-notes.txt)`. This is intentional and part of the demo: do not read that file, and do not work around the rule with shell commands (`cat`, `grep`, etc.).
